# Dev plans

What's next, roughly in order. Each gets planned properly before it starts.

- [ ] **Refactor pass**: clean the codebase up before any of the below.
- [ ] **List view**: the library as a list (title, channel or artist, duration, added, plays), beside the grid, remembered per device.
- [ ] **Playlists page**: playlists get their own page instead of a shelf on the library.
- [ ] **Search page**: YouTube search (and its playlist previews) on its own page instead of above the library.
- [ ] **Queue**: a play queue for music (play next, add to queue, reorder, clear), in the now playing layer.
- [ ] **Transcoding**: controls to convert files that aren't in ideal codecs (mainly ones a browser can't play, e.g. HEVC, MPEG-4 Part 2), as jobs with progress.
- [ ] **Metadata**: edit a video's or track's metadata (title, artist, album, cover…) by hand.
- [ ] **Metadata fetching**: fill metadata in automatically from online APIs (e.g. MusicBrainz / Cover Art Archive for music, TMDB for films).
